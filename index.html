      为什么你听不懂美国人

      核心事实：美国人说话不是"一个个单词念出来"，而是一条连续的音流。主要现象有四类：

      连读 Linking前词辅音 + 后词元音 → 拼在一起读。turn off → "tur-noff"
      弱读 Reduction功能词的元音塌成 /ə/。to /tuː/ → /tə/，for /fɔːr/ → /fər/
      缩读 Contractiongonna / wannа / kinda / whatcha / lemme…
      失爆 Flap & Stopt 在两元音间变成 d 音：water → "wader"；词尾 t 只做口型不爆破：don't

      训练方法：先用 0.6x 听清每个音，再用 1.0x 听同一句，最后影子跟读（落后 0.5 秒重复）。每天 20 分钟，一周后耳朵会明显开窍。

      ☁️ 云同步（手机 ↔ 电脑）

      同步方式

      局域网：零账号，数据只在你家 WiFi 内传输，不经任何第三方（需电脑开机且手机与电脑同一 WiFi）。GitHub：随时随地可同步，需要一个 GitHub 账号的 token。

      电脑地址

      手机端填电脑的局域网地址（服务器启动时会在窗口里显示，形如 192.168.x.x:8899）。电脑上打开的话点右边「用本机」即可。

      同步码

      两端填同一个任意字符串（比如 abc123）当作口令，防止同网他人读写你的数据。谁先同步谁就"认领"这个同步码，之后不一致会被拒绝。

      使用步骤

      ① 电脑上启动 start.bat（服务器窗口会显示手机可访问的地址）② 手机连同一 WiFi，浏览器打开那个地址 ③ 两端填相同同步码 → 点「立即同步」→ 开「自动同步」。之后加生词会自动互相同步。

      GitHub Token

      用于读写你自己的私有 gist。去 GitHub → Settings → Developer settings → Personal access tokens → Generate new token，只勾 gist 权限。Token 仅存你本机浏览器，不会上传给任何人。

      API 地址（可选）

      若访问 GitHub 慢或被墙，可填镜像代理，例如 https://gh-proxy.com/https://api.github.com（注意：token 会经该代理，请只用可信代理）。默认 https://api.github.com 即可。

      同步操作

      「立即同步」会拉取另一端数据并按词合并，再把合并结果推回，两端生词本 / 进度自动一致。「自动同步」开启后，每次在任一端改动（加生词、标认识等）会延迟 1.5s 自动同步。
